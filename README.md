# ♠ Hide & Hold'em ♣

브라우저 기반 **1인용 포커(드로우 포커) 게임**입니다.  
초기 자본금 500원으로 시작하여, 카드 족보에 따른 배당금을 받으며 가능한 한 오래 살아남는 것이 목표입니다.

## 게임 규칙 및 업적

### 기본 흐름

```text
[시작] → 카드 5장 뽑기 (베팅액 차감)
   ↓
[교체 단계] → 원하는 카드 선택 후 교체 (최대 2회, 1회당 베팅액의 50% 비용)
   ↓
[결과 확인] → 족보에 따라 배당금 지급 및 업적 체크
   ↓
자본금 ≥ 베팅액 → 다음 판 계속
자본금 < 베팅액 → GAME OVER
```

### 베팅 시스템

- **초기 자본금**: 500원 (+ 누적 보너스)
- **초기 베팅액**: 100원
- **베팅액 인상**: 현재 자본금에 비례하여 동적으로 자동 인상 (자본금의 20%, 최소 50원)
- **카드 교체 비용**: 베팅액의 50% (1회당)

### 족보 & 배당률

| 족보 | 배당률 | 설명 |
|------|--------|------|
| 하이카드 | 0배 | 아무 족보도 없음 |
| 페어 | 1.5배 | 같은 숫자 2장 |
| 투페어 | 2배 | 페어 2개 |
| 트리플 | 3배 | 같은 숫자 3장 |
| 스트레이트 | 5배 | 연속된 숫자 5장 |
| 플러시 | 7배 | 같은 무늬 5장 |
| 풀 하우스 | 10배 | 트리플 + 페어 |
| 포카드 | 15배 | 같은 숫자 4장 |
| 스트레이트 플러시 | 50배 | 스트레이트 + 플러시 |
| 로얄 스트레이트 플러시 | 100배 | 10, J, Q, K, A 플러시 |

### 🏆 업적 시스템 (Achievements) [신규 기능]

게임 내 특정 조건 달성 시 해금되는 업적 시스템이 적용되어 있습니다.
- '첫 승리', '풀하우스 달성', '자본금 1000원 돌파' 등 조건 달성 시 보상금이 지급됩니다.
- 획득한 보상금은 `bonusPool`에 누적되며, 게임 오버 후 **다시 시작할 때 초기 자본금에 합산**되어 지급됩니다.

### 하이스코어

- 게임 오버 시 **최고 도달 금액(maxMoney)**이 역대 최고 기록보다 높으면 `localStorage`에 저장됩니다.
- 키: `pokerHighScore`

## 핵심 로직 설명

### `src/utils/pokerLogic.js`

이 파일에는 3개의 export 함수가 있습니다:

#### 1. `createDeck()`
- 52장의 카드 배열을 생성합니다.
- 각 카드 객체: `{ suit, rank, value, id }`

#### 2. `shuffleDeck(deck)`
- Fisher-Yates 알고리즘으로 셔플합니다.

#### 3. `evaluateHand(hand)`
- 5장의 카드 배열을 받아 족보를 판별합니다.
- 반환 값: `{ name: string, multiplier: number, indices: array }`
- **스트레이트 특수 처리**: `A, 2, 3, 4, 5` (마운틴) 조합도 스트레이트로 인정합니다.

## 컴포넌트 & 상태 관리

### 게임 상태 머신 (`gameState`)

```text
   IDLE ←──────────┐
     │              │
     ▼              │
   DEAL ──(결과확인)──→ IDLE (자본금 충분)
     │              │
     ▼              │
  GAMEOVER ─(다시하기)─→ IDLE
```

### 주요 상태 변수

| 상태 | 타입 | 설명 |
|------|------|------|
| `money` | number | 현재 자본금 |
| `bet` | number | 현재 베팅액 |
| `playCount` | number | 누적 플레이 횟수 |
| `gameState` | string | 게임 상태 (`IDLE` / `DEAL` / `GAMEOVER`) |
| `deck` / `hand` | array | 남은 카드 덱 / 현재 든 5장의 카드 |
| `selectedCards` | array | 교체를 위해 선택된 카드의 인덱스 배열 |
| `highScore` | number | 역대 최고 기록 (localStorage 연동) |
| `unlockedAchievements`| array | 해금된 업적 ID 목록 |
| `bonusPool` | number | 업적으로 획득한 누적 보너스 자본금 |

### UI 렌더링 조건

```text
gameState === 'IDLE' && hand.length === 0  → 환영 메시지 + 시작 버튼
gameState === 'DEAL'                       → 카드 5장 + 족보 표시 + 교체/결과 패널
gameState === 'IDLE' && lastResult         → 결과 패널 + 다음 판 버튼
gameState === 'GAMEOVER'                   → 게임 오버 통계 + 다시 하기 버튼
```
